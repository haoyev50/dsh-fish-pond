# deep-fish-pond · 大肥鱼塘

大肥鱼塘里养鱼！这是一个给DSH（DeepSeek Harness）或桌面做的，给哦鲸鲸的鱼塘，插件可以基于dsh-bili-scroll爬取的数据来跟你对话。字号随时可调，你可以自己选择让她悬浮于桌面还是DSH上。你可以直接给deepseek扔过去这个github的地址，让她自己装。

![fish](assets/art/idle.webp)

## ⚠️ 依赖：必须先装 dsh-bili-scroll

这个插件**没有自己的内容来源**，它读的是 `dsh-bili-scroll`（刷B站）留下的产物：

| 说什么     | 从哪读                                                           |
| ------- | ------------------------------------------------------------- |
| **说精选** | `~/.dsh/bili-duty/out/YYYY-MM-DD.md` 里的 `### BV…` 块 → 标题 / 档位 |
| **说评论** | `~/.dsh/bili-duty/seen.md` 的「评论记录」表 → 再用登录态回 B站 取评论原文         |

**没装 `dsh-bili-scroll`，哦鲸鲸只会游、不会说话。**

```bash
dsh plugin add dsh-bili-scroll      # 先装这个
dsh plugin add deep-fish-pond       # 再装本插件
```

两个都装完，**重启 DSH**。

## 装完长什么样

- 右下角一只哦鲸鲸，平时在 idle / swim 之间轮换；
- 一句话浮在**她左侧**（靠屏幕左边时自动换到右侧）
- 空闲 45 秒没人理它，会自己从今天的台词里挑一句说；有新内容时优先说新的。

## 右键菜单

| 项               | 作用                        |
| --------------- | ------------------------- |
| 说精选             | 按「标题：… 挡位：值得看/可以看」重播今天的精选 |
| 说评论             | 重播她真发出去的评论                |
| 悬浮于桌面 / 悬浮于 DSH | 切换成独立置顶小窗，或收回 DSH         |
| 设置              | 调对话框字号（实时预览）、安装桌面悬浮环境     |
| 退出              | 收起成一个小鱼标，点一下回来            |

左键可以**拖动**鱼塘到任意位置（会记住）；右键菜单点外面任意处自动关闭。

## 桌面悬浮窗要 Python

「悬浮于桌面」是一个独立的 Python/Tk 窗口（Electron 这版不支持 Document PiP，`window.open` 又被宿主统一拒绝，这是唯一能真飘到桌面的路）。

需要 **Python 3 + Pillow**，插件会自己建一份环境：

```
~/.dsh/deep-fish-pond/.venv      # 插件自己的 venv
~/.dsh/deep-fish-pond/setup.log  # 安装日志
```

右键 → **设置 → 安装 / 重装** 即可，一次就够。装好之前点「悬浮于桌面」也会自动触发安装。

没装环境时，DSH 里内嵌那只照常工作，只是不能飘到桌面。

## 数据在哪

| 东西         | 路径                                                                                       |
| ---------- | ---------------------------------------------------------------------------------------- |
| 台词队列 / 去重表 | `~/.dsh/bili-duty/art/state.json`（`renders[]` 里每条一个 `{seq, kind, bv, title, tag, text}`） |
| 字号设置       | `~/.dsh/bili-duty/art/settings.json`                                                     |
| 日志         | `~/.dsh/bili-duty/art/art.log`                                                           |
| 桌面宠物 venv  | `~/.dsh/deep-fish-pond/`                                                                 |

**没有任何图片/视频产物**——早期版本会把台词烘焙成 webp，那套已经删掉。

## 工具（给 agent 用）

| 工具                | 作用                       |
| ----------------- | ------------------------ |
| `bili_art_status` | 看现在队列里有什么、桌面环境好了没        |
| `pond_setup`      | 建 venv + 装 Pillow（桌面悬浮用） |

## 已知限制

- 桌面悬浮窗用的是 Tk 的**颜色键控**透明（不是逐像素 alpha），边缘是硬的、没有半透明；
- OBS 的旧式窗口捕获抓不到透明窗，用「显示器捕获」或窗口捕获的 `Windows 10 (1903 and up)` 模式；
- 只在 Windows 上验证过。
